# NBA Optimizer — Phase 2 Implementation Plan (slates after tip-off, late swap)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the 🏀 NBA page right at any time of night: it opens on the slate Nathan can still enter, lists each slate's games with started ones grayed out, warns when lineups predate a tip-off, and offers a late-swap re-pick that changes only players in games that haven't tipped (players from in-progress games marked ⏱).

**Architecture:** The pipeline remembers every Classic slate seen today, so a slate that has started still gets rebuilt and published even after DraftKings drops it from the lobby. Each build records the slate's games with tip times and lines. A new engine module `nbadfs/late_swap.py` decides which games have started and re-picks a lineup with started players **fixed in their slots** (new `fixed` option on the optimizer). The app uses it on ⭐ Recommended, 🛠 My Lineup and 🔁 Tweak & Rebuild; the phone does this on published data, the Mac's Refresh rebuilds first.

**Tech Stack:** Python 3.14 via `./py` (hosted 3.12), pandas, numpy, PuLP + HiGHS, Streamlit 1.58, `zoneinfo` America/New_York.

**Spec:** `docs/superpowers/specs/2026-10-23-nba-optimizer-design.md` — §5 "Which slate" and "Late swap", §6 calls on the fixed lineup, Out players and slate choice. Phase 1 plan: `docs/superpowers/plans/2026-10-23-nba-phase1.md`.

## Global Constraints

- Everything from the phase 1 plan's Global Constraints still binds (`./py`; app code 3.12-compatible; NFL untouched; NBA files under `data/*/nba/`; no DraftKings login; atomic writes; `-W error` green; no network/real stages/launchctl/pmset in tests).
- All times compare in **America/New_York**: tip times are stored as naive ET ISO strings (`tip` in the pool, e.g. `"2026-10-25T19:00:00"`); every "now" is `datetime.now(ZoneInfo("America/New_York"))` made naive before comparing. Streamlit Cloud runs on UTC.
- A game has **started** when `tip <= now_et`.
- Default slate (spec): the earliest slate whose first game hasn't tipped; if every slate has started, the latest-starting slate that still has an untipped game; if every game has started, the latest-starting slate.
- Late swap (spec): after a game has tipped, a re-pick changes only players in games that haven't tipped; players from started games stay **in the same slot**. The app never picks a started-game player by itself; Nathan may lock ⏱ players from in-progress games.
- The fixed lineup is the one on screen: the recommended lineup for the chosen contest type, or 🛠 My Lineup if Nathan sent one there (spec §6).
- An Out player in the fixed lineup whose game hasn't tipped is replaced by the re-pick; a lock Nathan places on an Out player wins with ⚠ (unchanged from phase 1).
- Icon for in-progress players: `⏱`. Warning copy: `"⚠ Built before {away} @ {home} tipped off ({h:mm PM} ET) — refresh for the latest news."`
- Odds budget unchanged: re-picks and slate memory make no extra Odds API calls.

## Review Focus

1. **A slate has started by the 6:30 PM run and DraftKings no longer lists it** (today's "(Early)" 5:00 PM slate): it must stay in `slates.json`, be re-downloaded by draft-group id and rebuilt, and its folder must not be pruned → Task 1 `test_started_slate_missing_from_lobby_is_kept_and_rebuilt`.
2. **Hosted app on UTC**: a 7:00 PM ET tip must not count as started at 7:00 PM UTC (3:00 PM ET) → Task 3 `test_started_uses_eastern_time_not_utc`.
3. **Fixed started players leave no legal fill** (cap or 2-game rule): the re-pick explains why instead of crashing → Task 2 `test_repick_infeasible_message`.
4. **Every game in the slate has started**: re-pick is disabled with "All games have started — nothing left to change" → Task 2 `test_repick_all_started_returns_unchanged`, Task 4 `test_repick_button_disabled_when_all_started`.
5. **A started player in the fixed lineup is now listed Out** (left the game): he stays (he can't be changed); only untipped spots move → Task 2 `test_started_out_player_stays_fixed`.

### Task 2: Late-swap engine

**Files:** Create `nbadfs/late_swap.py`, `tests/nba/test_late_swap.py`; modify `nbadfs/optimizer.py` (`solve_lineup`), `nbadfs/lineups.py` (`generate_candidates`, `best_lineup` pass-through), `tests/nba/test_optimizer.py`.

**Interfaces — Consumes:** pool columns `dk_id, game, tip, slots, playable, salary`; `best_lineup`, `InfeasibleError`. **Produces:**
- `solve_lineup(..., fixed: dict[str, int] | None = None)` — each `slot → dk_id` pair forces that player into that exact slot (even if not playable or excluded-by-start); raises `InfeasibleError` if a fixed player isn't eligible for the slot. `generate_candidates` and `best_lineup` accept and pass `fixed`.
- `late_swap.started_games(pool, now_et: datetime) -> set[str]` (games with `tip <= now_et`, naive ET).
- `late_swap.in_progress_ids(pool, now_et) -> set[int]` (dk_ids in started games).
- `late_swap.repick(pool, sims, field, contest, lineup: list[int], now_et, *, locks=(), excludes=()) -> RepickResult` with fields `ids: list[int]` (slot order), `metric: float`, `kept: list[int]` (fixed started players), `changed: list[int]` (new players), `message: str`. Rules: lineup players whose game started → `fixed` in their current slot; every other started-game player → excluded unless in `locks`; lineup players in untipped games are free to change (Out ones drop out because they're not playable); `locks` from untipped games are ordinary locks. No started games → same as `best_lineup` with locks/excludes, `kept == []`. All games started → returns the lineup unchanged, metric of that lineup, `message == "All games have started — nothing left to change."`. Infeasible → `InfeasibleError` whose message names the fixed players' salary total and the remaining cap.

- [ ] **Step 1: Tests** — `test_fixed_slot_honored` (a SG/SF player fixed in F stays in F); `test_fixed_ineligible_slot_raises`; `test_started_games_and_in_progress` (tips 19:00 / 21:30, now 20:00 → only the 19:00 game); `test_repick_keeps_started_players_in_slots` (lineup with 3 players from a started game → same 3 in the same slots, ≥1 other spot can change, no other started-game player appears); `test_repick_never_adds_started_player_unless_locked` (a locked ⏱ player appears; without the lock he doesn't); `test_started_out_player_stays_fixed`; `test_untipped_out_player_replaced`; `test_repick_all_started_returns_unchanged`; `test_repick_infeasible_message`; `test_repick_before_tip_equals_best_lineup`.
