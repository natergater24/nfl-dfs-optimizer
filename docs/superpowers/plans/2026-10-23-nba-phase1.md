# NBA Optimizer — Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fill the 🏀 NBA page with real lineups for every DraftKings NBA Classic slate of the day — ⭐ Recommended (lineup + swaps per contest type), 🛠 My Lineup, 🔁 Tweak & Rebuild — built automatically at 2:00 PM and ~6:30 PM ET.

**Architecture:** A new engine package `nbadfs/` (rules, DK slates/salaries, Vegas, ESPN stats, projections, simulation, ownership/field, slot-assigning optimizer, lineups, build) and app package `nbadfs_app/`, reusing the sport-neutral NFL pieces (`nfldfs.sim_eval` metrics, `nfldfs.config` contest weights/metrics, `nfldfs.status`, `nfldfs.publish`, `nfldfs.teams.normalize_name`, `nfldfs_app.ui` formatting). A new `run_pipeline.py` stage `nba` writes `data/published/nba/`. **Simulations are not published**: the build publishes each slate's projections plus `n_sims`/`seed`, and the app regenerates the identical simulation matrix (deterministic) — keeps the git repo from growing ~1–2 GB a season.

**Tech Stack:** Python 3.14 via `./py` (hosted app 3.12), pandas 3, numpy 2, PuLP 4 + HiGHS, requests, Streamlit 1.58.

**Spec:** `docs/superpowers/specs/2026-10-23-nba-optimizer-design.md` (phase 1 = its §6 "Phases" item 1). Data-source facts: spike branch `nba-spike` (`nba_page.py`, `spike_nba_fetch.py`) — reference only, do not merge.

## Global Constraints

- Run Python only via `./py`; app code (`nba_page.py`, `nbadfs_app/`, anything they import) must stay Python 3.12-compatible.
- Never break NFL: every existing test stays green; NFL files, schedule and behavior unchanged except the shared builder component (Task 6), which must behave identically for NFL.
- NBA files live apart: `data/published/nba/`, `data/processed/nba/`, `data/raw/nba/` — an NBA failure never blocks an NFL run and vice versa.
- DraftKings NBA Classic only: lobby `https://www.draftkings.com/lobby/getcontests?sport=NBA`, Classic = `ContestTypeId == 70`; salaries `https://www.draftkings.com/lineup/getavailableplayerscsv?contestTypeId=70&draftGroupId={dg}`.
- Roster `("PG", "SG", "SF", "PF", "C", "G", "F", "UTIL")`, cap $50,000, 8 players, players from at least 2 different games.
- DK NBA scoring: point 1, made 3 +0.5, rebound 1.25, assist 1.5, steal 2, block 2, turnover −0.5, double-double +1.5, triple-double +3.
- Odds: The Odds API `basketball_nba`, `regions=us`, `markets=spreads,totals` (2 credits/call); skip the call when NBA lines are < 60 minutes old; no call at all when the lobby has no NBA Classic slate.
- Stats: sportsdataverse-data release `espn_nba_player_season_stats`, file `player_season_stats_{YEAR}.parquet` (YEAR = season end year; 2027 = 2026-27). Never call stats.nba.com or cdn.nba.com.
- DK `Status == "O"` → not playable; `Q`/`GTD` shown and allowed; a user lock on an Out player wins and is flagged ⚠.
- Ownership tiers as NFL: 🔥 Chalk ≥25%, Popular 10–25%, Moderate 5–10%, 💎 Contrarian <5%. Full-dollar money (`$7,500`).
- Hosted copy is read-only; no DraftKings login; no usernames published; atomic writes (`nfldfs.status.atomic_*`).
- Tests: `./py -m pytest -q -W error` green after every task; no network in tests (fixtures/monkeypatch); never run real stages, publish, launchctl or pmset in tests.
- Commit trailer: `Co-Authored-By: <model> <noreply@anthropic.com>`.

## Review Focus

1. **A player is ruled Out after the build** (DK `Status` flips to `O` on the 6:30 run): he must vanish from every recommended lineup, and a user lock on him must still build, with ⚠ → Task 4 `test_out_player_excluded_but_lock_wins_with_flag`.
2. **A game has no Vegas line yet** (lines often post late for back-to-backs): the build must not fail; that game's teams use the league-average implied total and are flagged → Task 3 `test_missing_line_uses_league_average_and_flags`.
3. **ESPN and DK spell names differently** (accents "Dončić", "Jr.", "III"): `normalize_name` matching; unmatched players fall back to DK average or salary baseline, and the build reports the match rate → Task 2 `test_stats_match_accents_and_suffixes`, Task 3 `test_rookie_and_unmatched_baselines`.
4. **Off day / All-Star break** (lobby has no NBA Classic slate): the `nba` stage is a no-op without an Odds API call; the page says "No NBA slate today" → Task 5 `test_nba_stage_noop_without_slates`, Task 6 `test_page_no_slate_message`.
5. **A multi-eligible player** (`SG/SF/F/G/UTIL`) must be placed in a slot that leaves the rest of the lineup legal, and the DK upload CSV must list IDs in slot order → Task 4 `test_slot_assignment_multi_eligible_and_two_games`.

### Task 3: Projections and simulation

**Files:** Create `nbadfs/project.py`, `nbadfs/simulate.py`, `tests/nba/test_project.py`, `tests/nba/test_simulate.py`.

**Interfaces — Consumes:** Task 1 pool, Task 2 `team_lines`, `match_rates`. **Produces:**
- `POOL_COLUMNS` (in `project.py`) = Task 1 columns + `minutes, rate, implied_total, opp_implied, line_missing:bool, median, sd, floor, ceiling` (+ `own_pct, tier` added in Task 4).
- `project(pool, lines, matched) -> DataFrame[POOL_COLUMNS minus own_pct/tier]`:
  - minutes and rate blend this season and last by games: weight on this season `w = g_cur / (g_cur + 8)`.
  - Players with neither season: `median = max(dk_avg, salary / 1000 * 4.5)`, `minutes = 0` (salary baseline; rookies).
  - Out players (`playable == False`) get `median = 0`; their projected minutes are shared among playable teammates whose `slots` overlap theirs (excluding UTIL), proportional to minutes, each capped at 40 minutes.
  - Vegas scaling: `rate × clip(implied_total / league_avg_implied, 0.85, 1.15)`, where league average = mean over the day's lines; teams without a line use the league average and `line_missing = True`.
  - `sd = 0.30 × median + 2.0`.
- `simulate(pool, n_sims, seed) -> np.ndarray float32 (n_sims × len(pool))`, deterministic for the same inputs. Shared game factor ~ N(1, 0.06) for both teams of a game, team factor ~ N(1, 0.04), player noise normal with `sd`, floored at 0; columns of non-playable players are all 0. After simulation, `floor`/`ceiling` = 15th/85th percentiles (filled by `summarize(sims, pool) -> pool`).

- [ ] **Step 1: Tests:** `test_blend_weights` (g_cur 0 → last season only; g_cur 8 → halfway); `test_out_minutes_redistributed` (a PG out with 30 min → teammates sharing G slots gain 30 total, none above 40); `test_missing_line_uses_league_average_and_flags`; `test_rookie_and_unmatched_baselines` (no stats, dk_avg 0, salary $4,000 → median 18.0); `test_simulate_deterministic_and_unbiased` (same seed → identical arrays; column means within 3% of median for 10,000 sims; teammates' columns positively correlated; Out columns all 0).

### Task 4: Ownership, field, optimizer and lineups

**Files:** Create `nbadfs/ownership.py`, `nbadfs/optimizer.py`, `nbadfs/lineups.py`, `tests/nba/test_ownership.py`, `tests/nba/test_optimizer.py`, `tests/nba/test_lineups.py`.

**Interfaces — Consumes:** Tasks 1–3; `nfldfs.sim_eval.lineup_scores`, `contest_metric`, `thresholds`; `nfldfs.ownership.ownership_tier`; `nfldfs.optimizer.InfeasibleError` (re-export). **Produces:**
- `estimate_ownership(pool) -> Series` (percent): score = `z(value) + 0.5·z(median) + 0.3·z(implied_total)` over playable players, converted with a softmax-style scaling so playable ownership sums to 800 (8 roster spots × 100%), capped at 70; non-playable 0. `add_ownership(pool) -> pool` with `own_pct`, `tier`.
- `sample_field(pool, n, rng) -> np.ndarray int (n × 8)` of **pool row indices** in slot order (same convention as NFL's field, so `nfldfs.sim_eval.lineup_scores` works unchanged): fill slots in random order, drawing among eligible, unused, affordable players with weight `own_pct + 0.05`; every lineup legal (cap, ≥2 games).
- `solve_lineup(pool, objective, *, min_salary=MIN_SALARY_DEFAULT, max_salary=SALARY_CAP, locks=(), excludes=(), previous=(), min_unique=MIN_UNIQUE_PLAYERS) -> list[int]` — 8 dk_ids **in ROSTER_SLOTS order**. Formulation: binary `x[i, s]` for player i × eligible slot s; each slot exactly one player, each player ≤ 1 slot; salary bounds; ≥ 2 distinct games (`y[g] ≤ Σ x` over the game's players, `Σ y ≥ 2`); locks force a player into some slot **even if not playable** (lock wins); excludes remove; uniqueness vs `previous` (sets of dk_ids). Raises `InfeasibleError` with a plain-English message.
- `build_all(pool, sims, field, contest_types=NBA_CONTEST_TYPES, n_candidates=30, seed=SEED) -> (lineups_df, swaps_df)` — same selection logic as `nfldfs.lineups.build_all` (candidates by contest weights, chosen by `contest_metric` against `lineup_scores(sims, field)`), lineups_df columns `contest_key, rank, slot, dk_id, metric`, up to 3 lineups per contest (rank 0 = recommended); swaps_df = top 5 single-player swaps per contest that keep the lineup legal (slot-compatible), columns `contest_key, out_id, in_id, delta`.
- `best_lineup(pool, sims, field, contest, *, locks=(), excludes=()) -> (list[int], float)` for 🔁 Tweak & Rebuild; adds `⚠ <name> is listed Out` messages via `out_lock_warnings(pool, locks) -> list[str]`.

- [ ] **Step 1: Tests:** `test_ownership_sums_and_caps` (playable sum 800 ± 0.5, max ≤ 70, Out = 0, tiers match NFL thresholds); `test_field_lineups_legal`; `test_slot_assignment_multi_eligible_and_two_games` (fixture where the optimum needs a `SG/SF` in F; result passes `rules.validate_lineup` with ROSTER_SLOTS; a pool built from one game only → `InfeasibleError` mentioning "2 games"); `test_locks_excludes_uniqueness`; `test_out_player_excluded_but_lock_wins_with_flag` (Out player never in `build_all` output; `best_lineup(..., locks=[out_id])` contains him and `out_lock_warnings` returns one ⚠ message); `test_build_all_shapes` (every contest key present, rank 0 lineups legal, swaps keep legality).
- [ ] **Step 2–4:** fail → implement → full suite passes.
