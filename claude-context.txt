NFL DFS LINEUP OPTIMIZER - PROJECT BRIEFING (2026-10-12)

PURPOSE
Personal-use engine that builds DraftKings NFL Sunday main-slate lineups for every DK
contest type (Head-to-Head, 50/50, Double Up, Multiplier 3x/5x/10x, Single Entry / 3-Max,
Tournament, Large-Field Tournament). Never logs in to DraftKings or enters contests.
Spec: docs/superpowers/specs/2026-10-11-nfl-dfs-optimizer-design.md
Plan 1 (engine, this build): docs/superpowers/plans/2026-10-12-nfl-dfs-engine.md
Branch: engine. Run via ./py (system Python 3.14). Tests: ./py -m pytest -q (94 pass).

DATA SOURCES
- DK lobby JSON (unauthenticated): https://www.draftkings.com/lobby/getcontests?sport=NFL
- DK salary CSV (official Export to CSV URL):
  https://www.draftkings.com/lineup/getavailableplayerscsv?contestTypeId={contest_type_id}&draftGroupId={draft_group_id}
- FINDING: DK's JSON "draftables" API returns 403 and must not be used; the CSV URL is the
  same file as the manual fallback (--salary-csv), so one parser serves both.
- nflverse via nflreadpy (player/team weekly stats). Vegas lines: The Odds API
  (ODDS_API_KEY in git-ignored env.txt; shared 500/month quota with MLB_Pipeline; ~2 units per run).
